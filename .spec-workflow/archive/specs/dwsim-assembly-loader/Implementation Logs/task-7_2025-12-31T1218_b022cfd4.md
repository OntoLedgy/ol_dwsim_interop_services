### Integrations

#### Integration
- **Description:** AssemblyLoader orchestrates the complete assembly loading workflow by integrating multiple components: PathResolver for multi-strategy path resolution, Assembly.LoadFrom for dynamic assembly loading, DwsimValidator for post-load validation, and LoadResult for structured result handling
- **Frontend Component:** AssemblyLoader.LoadDwsimAssemblies()
- **Backend Endpoint:** PathResolver.ResolveDwsimPath() → Assembly.LoadFrom() → DwsimValidator.ValidateInstantiation()
- **Data Flow:** 1) Resolve DWSIM path using PathResolver or config → 2) Loop through RequiredAssemblies → 3) LoadAssembly() calls Assembly.LoadFrom() for each → 4) Create AssemblyInfo for each loaded assembly → 5) Check timeout on each iteration → 6) Call DwsimValidator.ValidateInstantiation() if config.ValidateAfterLoad is true → 7) Return LoadResult.SuccessResult() with all assemblies or LoadResult.FailureResult() with error details

#### Integration
- **Description:** Error handling integration: LoadAssembly wraps all assembly loading exceptions (FileNotFoundException, FileLoadException, BadImageFormatException, TypeLoadException) into DwsimLoadException with appropriate ErrorCode and context, which flows up to LoadDwsimAssemblies and gets wrapped in LoadResult for structured error reporting
- **Frontend Component:** AssemblyLoader.LoadAssembly()
- **Backend Endpoint:** DwsimLoadException with ErrorCode
- **Data Flow:** Assembly.LoadFrom() exception → Catch specific exception types → Log with Serilog → Wrap in DwsimLoadException with ErrorCode (AssemblyNotFound, AssemblyLoadFailure, TypeLoadFailure) → Propagate to LoadDwsimAssemblies → Catch and wrap in LoadResult.FailureResult() → Return to caller with structured error
